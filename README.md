# ObsForce anonymous supplementary page

Static site source for the ICLR 2027 review page at https://vid-force.github.io/obsforce/. All deployable files live in this folder.

The page quotes the frozen Eval metrics from `../tables/results_macros.tex` and uses figures from `../figures/`. Update these together if the paper's model or results change. Do not add a paper PDF while the draft contains revision colors, placeholders, or identifying metadata. Add code, checkpoint, and video links only after their anonymous destinations exist.

Publish this folder to https://github.com/vid-force/obsforce from the anonymous `vid-force` account. ICLR 2027 requires linked supplementary material to remain anonymous. The repository has a write-enabled deploy key limited to this repository; the private key stays in `~/.ssh/`. Never place a token or private key in this folder or repository.
